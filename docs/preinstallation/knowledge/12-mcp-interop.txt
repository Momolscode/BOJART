Configurer le chemin absolu du Python isolé et le même BOJART_MEMORY_STATE que Jarvis. Avec le client réel choisi, tester démarrage, découverte des outils, recherche et contexte cité ; confirmer la version réellement négociée. Vérifier les effets de chaque outil : une lecture reste une lecture, memory_note ajoute seulement une proposition. Ne pas introduire de serveur tiers donnant exécution Python, shell ou commande machine au prétexte qu’il porte le nom MCP.
