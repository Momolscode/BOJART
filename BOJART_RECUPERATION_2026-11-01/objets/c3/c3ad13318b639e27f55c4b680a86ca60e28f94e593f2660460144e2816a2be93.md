# Mouvement et ancrage 2D — reconstruction réellement éprouvée

Cible : `Avalonia.Base.dll` du package NuGet **Avalonia 12.1.4**, framework net8.0.
Licence MIT conservée dans `LICENSE_AVALONIA.txt`. L’objectif est une petite
boîte de calcul pour nos vidéos, pas une copie de l’interface d’Avalonia ou
d’un créateur.

## Ce que REA a effectivement établi

REA 6.8.0 a lu les métadonnées et décodé les instructions CIL de 46 méthodes
dans quatre types sélectionnés, sans troncature ni type demandé manquant.
Le wrapper Bounce appelle un helper dont le nom a été résolu dans un
`call_edge`. Une seconde inspection ciblée a décodé ce helper. Les bundles
complets ont été exportés avant la fermeture des connexions.

Identité du binaire :

- SHA-256 : `ffaf5263f964ea313ed29361c0dc86ed20fa7fda1473aefa687fde3a90622f8d`.
- MVID : `6b8c048b-6062-4c98-bbb3-ddb072211ea2`.
- Version d’assembly : `12.1.4.0` ; CIL, architecture managée AnyCPU.
- Evidence membres : `ev_2a0403d54f2b2689462f04115f18f2327df1a0875dcf92e368cd0448efb57504`.
- Evidence helper : `ev_18449a2db936b4854c8aec96989e58d7aa93b90fc8d5e047c008a09d4b6c5a27`.

L’inspection statique n’a chargé ni exécuté l’assembly et n’a pas décompilé
de C#. `motion_primitives.py` est une reconstruction Python originale à
partir des instructions observées. Aucun fichier source du dépôt amont n’a
été utilisé pour établir ces algorithmes ; sa licence a ensuite été conservée.

## Quatre briques utiles

| Brique | Comportement récupéré | Usage proposé dans Marwin |
| --- | --- | --- |
| Cubic in/out | Deux branches autour de 0,5 ; progression brute non bornée par la fonction | Une entrée courte de cartouche avec accélération marquée au milieu |
| Sine in/out | `0,5 × (1 − cos(πt))` | Un déplacement ou une variation d’intensité plus étalés sur la durée |
| Bounce out | Quatre polynômes, seuils 4/11, 8/11 et 0,9 | Une seule arrivée d’objet ou d’étiquette, avec rebonds dosés |
| Affine 2D | Coordonnées de sortie et ordre de composition explicites | Garder un label dans les coordonnées d’un élément animé |

Ces usages sont des choix de réalisation, sans bénéfice de rétention mesuré.
Le Bounce de cette version utilise des coefficients précis conservés depuis
le CIL : une autre recette « bounce » courante n’a pas été substituée.

La matrice utilise les vecteurs lignes :

`x' = x*m11 + y*m21 + m31`, `y' = x*m12 + y*m22 + m32`.

`A.append(B)` applique A puis B ; `A.prepend(B)` applique B puis A.
Cette différence change aussi la translation, donc l’ancrage d’un texte.
Les angles sont en radians. La reconstruction exclut les cas de perspective
de la classe originale : ce n’est pas un suivi 3D ni une homographie.

## Vérification contre le binaire original

Après la reconstruction, un oracle séparé a chargé le même DLL par pythonnet
et CLR **10.0.14** et exécuté ses méthodes originales :

- Trois courbes sur **10 031 entrées chacune**, y compris les seuils et leurs
  voisinages et quelques extrapolations finies : **30 093 comparaisons**.
- **1 000 cas** de matrices et points : transformation, append, prepend et
  rotation autour d’un pivot, soit **8 000 coordonnées comparées**.
- **Aucun écart numérique constaté** sur ces valeurs ; erreur absolue maximale 0.
- Six tests d’invariants passent également.

La preuve est `../evidence/motion/original_runtime_comparison.json`.
Elle ne démontre pas une équivalence universelle : NaN, infinis, inversion,
perspective et rendu graphique d’un logiciel ne sont pas testés. Elle ne
valide ni reconnaissance de Morgan, ni jeu, ni appréciation artistique.

## Rejouer

Les primitives et leurs six tests nécessitent seulement Python :

```bash
python -m unittest discover -s . -p 'test_motion.py' -v
```

Pour l’oracle, installer pythonnet dans un environnement séparé et disposer
du runtime compatible ainsi que du DLL de même empreinte :

```bash
python verify_original.py --dll /chemin/Avalonia.Base.dll \
  --runtime-config /chemin/oracle.runtimeconfig.json \
  --dotnet-root /chemin/dotnet \
  --out /chemin/comparaison.json
```

Un exemple de configuration pour le runtime employé est
`{"runtimeOptions":{"tfm":"net10.0","framework":{"name":"Microsoft.NETCore.App","version":"10.0.14"}}}`.
Le chargement de cet oracle est une exécution explicite et séparée ; il ne
fait pas partie du parseur statique REA.

La progression à fournir est normalement `t ∈ [0,1]`. La borner au montage
est une décision de notre adaptateur ; les courbes reconstruites conservent
le comportement brut du binaire.
