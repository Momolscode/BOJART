# Import de statistiques propriétaire

Ce module lit un JSON déjà obtenu par un accès propriétaire autorisé. Il n’appelle aucun réseau, ne connecte aucun compte et ne publie rien. Aucun compte Instagram n’était relié lors du contrôle ; les quatre tests utilisent exclusivement des données fictives de validation.

```bash
python import_owner_insights.py /chemin/owner_insights.json --out /chemin/observations.json
python -m unittest discover -s . -p 'test_*.py' -v
```

Le module refuse les réponses indisponibles et les accès publics. Il conserve les valeurs inconnues à null, les vrais zéros à zéro, transforme explicitement les millisecondes en secondes et conserve fenêtre et pagination quand elles sont données. Une moyenne regardée de 120 % reste possible sans devenir un taux de personnes ayant terminé. Le taux de saut reste brut tant que son unité et sa définition ne sont pas confirmées. Aucun résultat causal ou score viral n’est calculé.
