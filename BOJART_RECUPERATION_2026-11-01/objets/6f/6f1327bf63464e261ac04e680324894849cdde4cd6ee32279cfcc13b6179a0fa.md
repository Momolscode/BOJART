## Chemin effectivement raccordé

`FastAPI ou MCP → LangGraph → contrôle existant → DBOS/SQLite → journal du pilote`

Le graphe conserve séparément rapport documentaire et décision. DBOS garde le
résultat avec un identifiant dérivé de l'entrée et de la version du pipeline.
Le journal existant conserve un événement dédoublonné et l'empreinte du résultat.
Le même audit `render` demandé dans deux processus distincts a exécuté l'étape une
fois et créé un seul événement. Cela ne prouve pas la reprise d'un paiement, la
tolérance à une panne disque, un cluster ou un rendu distant.

L'API n'accepte que le projet `marwin-studio` et les étapes `develop`, `render`,
`publish`. Ces étapes sont des contrôles, jamais des commandes d'exécution.
MCP expose seulement `studio_status` et `studio_audit` via stdio. Un client de test
a réellement appelé le serveur dans un autre processus. Il n'est pas inscrit
dans le client personnel de Morgan.

## Reproduire

Versions d'exécution éprouvées : Python 3.12.14, Node 24.22.1 sur Linux. Les
dépendances Python installées sont figées dans `requirements-lock.txt`.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python cli.py --stage render
.venv/bin/python -m unittest discover -s tests -v
```

Pour ouvrir une API **locale** : définir `MARWIN_LOCAL_TOKEN` avec un jeton choisi
sur le poste, puis exécuter `.venv/bin/uvicorn api:app --host 127.0.0.1 --port 8765`.
Envoyer `Authorization: Bearer …` pour `/studio` et `/audit`. Ne pas exposer cette
API sur Internet : TLS, identité multiutilisateur et exploitation durable ne sont
pas implémentés. Aucune clé de compte ou de fournisseur n'est incluse.

Pour le client MCP choisi, la commande est le chemin absolu vers
`.venv/bin/python` et l'argument celui vers `mcp_server.py`. Il s'agit d'une
configuration à appliquer sur le poste cible, pas d'une connexion déjà faite.

```sh
# Depuis legacy/ pour les imports du pilote :
# ../.venv/bin/python -m unittest discover -s tests -v
# Depuis control/MARWIN_Atelier_Controle/ :
# ../../.venv/bin/python -m unittest -v test_controle
node build_atlas.mjs
```

Les commandes des tests historiques sont exécutées depuis leur dossier,
afin de conserver leurs imports originaux.
`MARWIN_RUNTIME_DIR` peut désigner un répertoire de test séparé. À défaut, les
bases et traces sont créées dans `runtime/`. Les bases éphémères de test ne sont
pas distribuées.

## Outils média et services

`node/package-lock.json` fige HyperFrames 0.8.210, Hypit 0.3.1, Fontsource 0.2.0 et
Chromium 153.0.0. `npm ci --prefix node --ignore-scripts` réinstalle ces paquets,
sans télécharger de poids d'IA ou activer de compte. Lire leurs instructions
avant de lancer un rendu. HyperFrames et Hypit sont deux chemins distincts ;
Hypit n'est pas traité comme un simple lanceur HyperFrames.

La CLI Hypit et la CLI HyperFrames ont été exécutées ici. Les quatre exports
antérieurs restent les preuves datées du 28 octobre, référencées dans la mémoire.
Aucun nouveau film ou rendu par ces deux moteurs n'a été lancé le 29 octobre.

`adapters.py` prépare les contrats Cobalt et SearXNG, avec essais sur réponses
fictives explicitement identifiées. Il n'émet aucune requête. Une instance
autorisée manque pour chaque service ; une instance publique ne sera pas choisie
automatiquement. Temporal est un SDK alternatif installé, sans serveur démarré.
REA, OTIO, SAM, Remotion, LTX/Wan/Shotcraft restent à leurs états documentés dans
`data/capabilities.json`. Ce catalogue n'atteste pas leur installation globale.
