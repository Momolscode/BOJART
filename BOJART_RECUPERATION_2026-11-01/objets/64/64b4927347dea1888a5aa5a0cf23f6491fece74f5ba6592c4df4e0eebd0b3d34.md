## Publication par une session autorisée
Git et `gh` doivent déjà être installés ; l'authentification se fait via l'outil, jamais en collant un token dans le chat. Une fois le compte choisi, préparer le plan :

    python PUBLIER_GITHUB.py --repo OWNER/bojart-jarvis --delivery CHEMIN_DU_DOSSIER

Remplacer OWNER et le chemin. Aucun effet distant par défaut. Ajouter `--execute --create-private` seulement lorsque la création de cette destination privée est autorisée. Le script vérifie le propriétaire, la visibilité, les fichiers et le commit ; il pousse une branche de récupération sans force-push, joint le coffre et les preuves à une Release, puis retélécharge pour vérifier. Aucun site n'est déployé et aucune donnée client n'est importée. Un conflit provoque un arrêt, pas un écrasement.

## Deux sauvegardes au minimum
Garder une copie indépendante de ce pack. Le bundle ne contient pas tous les originaux du coffre, et un clone Git seul ne télécharge pas les fichiers attachés à la Release. Les hashes détectent les changements mais ne sont pas une signature d'éditeur.
