# Recherche technique — 1 novembre 2026

Choix d’architecture adaptés au corpus, pas classement de performances.

| Source primaire | Apport | Décision et état |
|---|---|---|
| [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence) | Checkpoint de fil et mémoire entre fils distincts | Garder M07, ajouter mémoire documentaire locale |
| [SQLite FTS5](https://www.sqlite.org/fts5.html) | Index textuel et BM25 | Recherche locale citée implémentée, sans embeddings |
| [DVC remote](https://doc.dvc.org/user-guide/data-management/remote-storage) | Versions de données sur NAS/stockage objet | Option ; remote non configuré |
| [GitHub gros fichiers](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github) | Limite Git ordinaire de 100 Mio | Gros médias externes, références SHA-256 |
| [Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage) | Pointeurs et octets séparés | Alternative à DVC, non activée |
| [TypeSafe modèles](https://docs.typesafe.ai/models) | Jev 1.14 traite du texte via service | Adaptateur facultatif après ASR ; pas de Jev local revendiqué |
| [Pipecat UIWorker](https://docs.pipecat.ai/pipecat/learn/ui-worker) | État d’interface et actions déclarées | Piste conversation continue, non activée |
| [Concurrence GitHub](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency) | Jobs d’un groupe sérialisés | CI par branche ; tête du push contrôlée séparément |

Le problème observé concerne d’abord provenance, versions et contradictions. Un index vectoriel prématuré retrouverait aussi les anciennes erreurs. La base lexicale donne un comportement inspectable. Comparer ensuite recherche hybride sur un jeu stable : état M07, place de Jev, G2/R03, matériel inconnu, sites distincts et absence de publication. Mesurer bonnes sources, citations, fausses disponibilités et latence.

Aucun abonnement, poids de modèle, stockage cloud ou service de conversation acheté ou activé.
