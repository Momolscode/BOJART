# Import de l'archive complète — statut en attente

Le paquet documentaire et média BOJ.ART/Marwin est préparé, mais **n'est pas versé dans ce dépôt public**.

## Raison
L'archive contient des captures de conversation, des références de fichiers, des médias de travail et des documents dont les droits de publication ne sont pas tous vérifiés.

## Étapes d'import
1. Passer ce dépôt en **Private** dans GitHub Settings.
2. Vérifier les médias, données personnelles, clés et licences avant chaque ajout.
3. Reprendre l'archive locale et contrôler les empreintes SHA-256.
4. Stocker les médias volumineux avec Git LFS ou dans un stockage privé avec des manifests traçables.
5. Ajouter les fichiers par commits distincts : documents, rendus et médias.
6. Vérifier que chaque fichier importé est accessible et que la branche finale pointe vers le bon commit.

Les liens externes des générations Higgsfield ne prouvent pas la sauvegarde des MP4.
