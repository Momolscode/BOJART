# Montage éditable depuis une analyse locale

`export_timeline.py` produit un projet OpenTimelineIO avec pistes vidéo et audio, des coupes candidates, une liste CSV et des marqueurs d’énergie. Il travaille à partir d’un export vidéo aplati ; les calques et effets d’origine ne sont pas récupérés. Les coupes restent à juger visuellement.

Installer `opentimelineio==0.18.1` dans un environnement Python isolé, puis :

```bash
python export_timeline.py /chemin/analysis.json --media /chemin/film.mp4 --out /chemin/projet.otio
```

L’empreinte du média doit correspondre à l’analyse. Une cadence moyenne/nominale incohérente ou un décompte d’images incompatible est refusé. L’arrondi est effectué sur la grille d’images déclarée ; un média à cadence variable doit d’abord être conformé selon ses timestamps. Les flashes ne deviennent pas automatiquement des coupes.

Le lien média est son nom de fichier : placer la vidéo auprès du projet ou la relier dans le logiciel choisi. L’import dans un éditeur précis n’est pas testé ; certains logiciels demandent un adaptateur ou une conversion. Aucune compatibilité universelle n’est promise.

Preuve réelle : `evidence/timeline/Lumiere_V1_Analyse_Editable.otio`, cinq segments vidéo et une piste audio parallèle, 451 images à 24 i/s, relecture par la bibliothèque OTIO sans changement de durée. Quatre tests ont vérifié le tour écriture/relecture, l’identité source et les incohérences de temps. Ce projet est un support de contrôle historique ; il ne réactive pas la scène du bocal, mise en réserve dans le pilotage récent.
