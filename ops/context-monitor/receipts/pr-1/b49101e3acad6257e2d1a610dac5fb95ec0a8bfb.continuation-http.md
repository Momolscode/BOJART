# Reprise de l'audit HTTP — 2 novembre 2026

État : **partiel**. Révision examinée : [b49101e3acad6257e2d1a610dac5fb95ec0a8bfb](https://github.com/Momolscode/BOJART/commit/b49101e3acad6257e2d1a610dac5fb95ec0a8bfb).

Une requête HTTP incomplète pouvait immobiliser les actions des autres fenêtres. La réception du JSON se fait maintenant avant la prise du verrou global, avec une taille, une capacité et un délai d'inactivité bornés. Une mutation commencée conserve son verrou : les sauvegardes et la fermeture attendent toujours sa fin.

Le correctif refuse aussi explicitement les jetons de démarrage non ASCII et les longueurs HTTP ambiguës. Le test de lien symbolique dans une archive utilise désormais une base toujours présente, sans dépendre des médias privés.

## Limites

Trois tests M05 avec médias privés ne sont pas exécutés localement : restauration complète des médias, disparition de média et téléchargement de leur snapshot. Ils ne sont pas déclarés validés.

Aucun navigateur, microphone, modèle réel, GPU, calcul géométrique ni commande physique n'a été qualifié. Le délai existant concerne l'inactivité de réception, pas une échéance totale absolue. Les tests à deux secondes démontrent l'indépendance des requêtes, pas une latence garantie du PC cible. La correction ne permet pas d'attribuer les pics Windows/LangGraph observés dans les simulations précédentes.
