# BOJ.ART — préparation Jarvis avant accès au PC

Ce pack est un **kit de reprise et d'audit non destructif**, pas un installateur déjà validé.
Il sert à Claude Code ou à un agent local autorisé pour établir l'inventaire du PC avant de sélectionner les modèles et installer les moteurs.

## Démarrage
1. Copier ce dossier sur le PC cible.
2. Ouvrir `MISSION_CLAUDE.md` dans Claude Code sur cette machine, avec les autorisations nécessaires.
3. Lancer `audit_pc.py` avec Python 3 si disponible. Le script est en lecture seule et écrit un rapport JSON dans le dossier courant.
4. Examiner le rapport avant toute installation. Ne pas transmettre les chemins privés, secrets ou médias au cloud sans accord.

## Conditions de réception
- Modèles IA choisis à partir de mesures de VRAM/RAM et benchmarks locaux.
- Réponse vocale et trois écrans vérifiés sur la machine.
- Au moins une FDM et une résine qualifiées de bout en bout.
- Reprise sans double lancement d'un travail.
- Fichiers STL et rushes retrouvables après restauration.
- Jev optionnel ; affichage déterministe disponible hors ligne.
