# Tests prioritaires
- [ ] Changement de projet pendant l'analyse : aucune réponse ne s'applique au mauvais dossier.
- [ ] Requête identique répétée : pas de deuxième départ machine.
- [ ] Réponse machine perdue : état inconnu, pas de relance automatique.
- [ ] Fichier STL en pouces : unité conservée et convertie explicitement.
- [ ] Pièces FDM/résine mixtes : affectation par pièce, pas par taille uniquement.
- [ ] Fichier vidéo déplacé : index indique indisponible, ne perd pas sa provenance.
- [ ] Coupure Internet : commande locale et affichage restent utilisables.
- [ ] Restauration : STL, rushes, versions et devis cohérents.
- [ ] Jev indisponible : affichage déterministe de secours.
- [ ] Aucune demande client privée n'apparaît dans un écran public.
