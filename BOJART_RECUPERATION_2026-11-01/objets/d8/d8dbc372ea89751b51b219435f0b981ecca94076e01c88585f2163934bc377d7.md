# Noyau de lumière original et test de protection

Ce code est notre propre fixture. Il n’est pas le projet original d’un Reel et n’a pas été récupéré chez un artiste. Le sous-dossier `shipped` est un petit artefact autonome livré pour tester l’inspection statique REA ; le code éditable et ses tests se trouvent ici.

L’enveloppe commence à 0, capture entre 0,5 et 1,4 seconde, tient jusqu’à 2,6 s, puis libère entre 2,6 et 3,6 s. Chaque phase emploie une interpolation cubique monotone, sans dépassement. Une lumière gaussienne varie en douceur ; le masque a priorité et retourne exactement les octets RGB initiaux dans sa région protégée.

Lancer les tests : `node --test light-envelope.test.js` depuis ce dossier. Aucune dépendance Node supplémentaire.

`render_protected_demo.py` est une démonstration vidéo locale de quatre secondes. Elle protège toutes les lignes à partir de y=120 dans le rush natif 512×910 : le sujet et une grande marge restent hors effet. Seule une bande de plafond au-dessus de cette limite reçoit une modulation. Ce masque rectangulaire a été choisi après inspection du contact du rush ; ce n’est pas un détourage automatique ni un suivi général de personne. Pour une autre prise, il faut redéfinir et contrôler le masque.

Le script mesure l’identité avant encodage de chaque pixel protégé, puis vérifie le master FFV1 sans perte. Le MP4 H.264 est un aperçu compressé : ses pixels peuvent différer de la source à cause de l’encodage. Le master et la preuve numérique ont une portée technique, sans preuve de ressemblance appréciée, de jeu, de contact avec un bocal ou d’effet sur l’audience.

La scène « Une lumière pour plus tard » reste à reprendre. Cette bande de plafond animée ne constitue ni ce film ni un nouveau jeu de Morgan.
