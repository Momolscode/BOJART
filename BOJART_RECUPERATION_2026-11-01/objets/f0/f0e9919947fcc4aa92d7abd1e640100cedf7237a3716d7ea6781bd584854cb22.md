# Installation et preuve REA

Installation locale épinglée avec dépendances verrouillées :

```bash
python install_rea.py --prefix /chemin/rea-local --register-codex
```

Le dossier de destination doit être vide ; le script y copie les fichiers de dépendances du kit puis exécute `npm ci`. Node est contrôlé avant toute installation. `--dry-run` permet de voir ce plan sans écrire. Une réinstallation de contrôle dans un dossier distinct a réellement réussi : 176 paquets, REA 6.8.0 ; aucune nouvelle inscription de client.

Le drapeau optionnel inscrit le serveur Codex et conserve les sauvegardes prévues par REA ; sans ce drapeau, seul le package local est installé. Lire le plan de REA avec `rea setup --client codex --skill=false --dry-run --json` si l’on souhaite le revoir avant application. Recharger un client pour y faire apparaître un nouveau serveur. L’installateur fourni n’installe pas de moteurs natifs, ne change pas de skill personnel et ne modifie aucune protection de processus.

Contrôle d’environnement : `python diagnose_environment.py`. Une incohérence entre PID API et `/proc` exige un environnement de processus cohérent ; ne pas fournir une fausse sortie `ps` et ne pas désactiver la garde de REA.

Sonde MCP de notre artefact JavaScript original :

```bash
python mcp_probe.py --rea /chemin/rea-local/node_modules/.bin/rea --target /chemin/kit/toolkit/effects/shipped --out /chemin/preuve-mcp
```

Ici, initialisation/catalogue réussis mais l’analyse JavaScript a été refusée par la garde de processus. `binary_session` ne constitue pas non plus un succès global. Un contrôle intégré distinct a réellement inspecté un fichier `.pyc` original, généré depuis `render_protected_demo.py` avec Python 3.12. On peut préparer un `.pyc` puis ajouter `--python-pyc /chemin/fixture.pyc` à la sonde. Il s’agit d’en-tête, d’objets et d’empreintes, sans décompilation ni récupération de source.

Les reçus conservent ces résultats séparément. Voir `evidence/rea_mcp/` et `evidence/environment_diagnostic.json`. Le code source original livré reste disponible indépendamment de REA.
