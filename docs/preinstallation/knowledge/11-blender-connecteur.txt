Connecter Blender par opérations bornées

Portée : préparation documentaire ; tour Windows non qualifiée ; aucune instruction d’exécution implicite.

Blender peut servir la modélisation artistique et le rendu, tandis que CadQuery conserve les familles paramétriques prévues. La branche 5.2 LTS est documentée ; sélectionner le binaire exact après inventaire de la tour et préserver les fichiers originaux.
Pour un futur connecteur, définir d’abord une petite opération vérifiable : ouvrir un asset approuvé, inspecter dimensions/collections, produire une miniature et enregistrer une copie dans un dossier neuf. Les fichiers .blend peuvent contenir des scripts ; autoexec désactivé ne transforme pas un script Python explicitement exécuté en code sûr. Seuls des scripts relus et bornés sont autorisés. Le résultat artistique doit être comparé aux références authentiques, indépendamment du succès technique du rendu.

Sources primaires :
blender-cli — https://docs.blender.org/manual/de/5.1/advanced/command_line/arguments.html
blender-lts — https://projects.blender.org/blender/blender/milestone/33
