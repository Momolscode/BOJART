# Publication GitHub : état et règles

- Aucun dépôt ni branche distante n'a été créé ou modifié lors de cette préparation.
- Deux comptes apparaissent dans la connexion : Momolscode et EaglemicBACH.
- L'utilisateur doit choisir le compte et, si applicable, le dépôt existant.
- Préférer un dépôt privé pour cette archive de travail ; ne pas rendre publics les médias et
  le JSON de contexte sans revue explicite.
- Conserver l'historique existant. Utiliser une branche ou un sous-dossier nouveau ; pas de force-push.
- Ne pas déposer de clés, jetons, poids de modèles ou caches d'outils.
- Ne pas activer de publication web, de déploiement ou de nouvelle génération lors de l'import.
- Vérifier le commit réellement présent sur GitHub avant d'annoncer un envoi réussi.
