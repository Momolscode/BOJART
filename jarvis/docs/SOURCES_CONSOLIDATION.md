# Sources primaires relues le 30 octobre 2026
- GitHub, sauvegarde dépôt et LFS : https://docs.github.com/en/repositories/archiving-a-github-repository/backing-up-a-repository
- GitHub, gros fichiers : https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github
- Git, bundle : https://git-scm.com/docs/git-bundle
- TypeSafe, modèles et rôle de Jev : https://docs.typesafe.ai/models
- LangGraph, persistance : https://docs.langchain.com/oss/python/langgraph/persistence

Le bundle restitue les commits contenus. Les objets LFS éventuels se sauvegardent séparément ; ce dépôt de consolidation n'utilise pas de pointeurs LFS. Les binaires d'archives sont prévus comme actifs de Release privée. Le clone Git ne sauvegarde pas D1, secrets, machine locale, médias non récupérés ou discussions GitHub.
