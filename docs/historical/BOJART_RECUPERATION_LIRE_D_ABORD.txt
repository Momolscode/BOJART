RESTAURER UNE ARBORESCENCE (OPTIONNEL)
Python 3.9 ou plus, sans module supplémentaire ni réseau :
  python RESTAURER.py --list
  python RESTAURER.py --verify
  python RESTAURER.py --source libfile_875f76c239cc8191a4c147a11293c9ff --destination JARVIS_M07_RESTAURE
Le dossier destination ne doit pas exister. Les fichiers existants ne sont jamais écrasés.
  python RESTAURER.py --all --destination BOJART_TOUT_RESTAURE
Pour déplier aussi les archives imbriquées, ajouter --unpack-nested. Les ZIP imbriqués originaux sont eux aussi conservés.
Les liens symboliques sont restitués comme fichiers texte .symlink.txt ; les caractères de noms incompatibles avec Windows sont échappés et documentés.
Le programme ne lance aucun script récupéré. Les originaux ZIP de premier niveau restent accessibles à leur lien source ; le programme restaure leur contenu, sans prétendre recréer un ZIP binaire identique.
